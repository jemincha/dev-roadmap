# 01. Calculator

## Rebuilding My Development Foundation

컴퓨터공학 4학년을 앞두고 있지만, 스스로에게 한 가지 질문을 던졌다.

**"나는 정말 서비스를 만들 수 있는 개발자인가?"**

학교에서 자료구조, 운영체제, 데이터베이스, 소프트웨어 공학 등 다양한 전공 지식을 배웠다. 정보처리기사 자격도 취득했다.

하지만 이론적인 지식과 실제 서비스를 설계하고 구현하는 능력 사이에는 분명한 간극이 있었다.

AI 코딩 도구의 발전으로 누구나 빠르게 결과물을 만들 수 있는 시대가 되었지만, 개발의 기본기가 부족한 상태에서 AI가 생성한 코드를 활용하면 작은 프로젝트조차 구조를 이해하지 못한 채 기술 부채에 막히는 경험을 반복하게 된다.

그래서 가장 기본적인 프로젝트부터 다시 시작하기로 했다.

첫 번째 프로젝트는 계산기다.

누군가에게는 너무 쉬워 보이는 프로젝트일 수 있다. 하지만 이 작은 프로젝트 안에는 웹 개발의 가장 기본적인 흐름이 담겨 있다.

* 사용자 입력 처리
* DOM 조작
* 이벤트 기반 프로그래밍
* 상태 관리
* 타입 변환
* 함수 분리와 리팩토링

이 프로젝트의 목적은 계산기를 만드는 것이 아니라, 개발의 기본 단위를 다시 이해하고 앞으로 더 복잡한 서비스를 만들기 위한 기반을 다지는 것이다.

## Key Learnings

### DOM & Event Handling

사용자의 버튼 입력을 감지하고 JavaScript 로직과 화면을 연결하는 기본적인 흐름을 구현했다.

```javascript
button.addEventListener("click", function(){
    ...
});
```

---

### State Management

계산기의 상태를 다음 변수로 관리했다.

```javascript
currentInput
previousInput
operator
```

화면에 보이는 값과 프로그램 내부에서 관리하는 상태가 다르다는 것을 이해했다.

---

### Type Conversion

사용자 입력은 문자열로 관리하고, 계산이 필요한 순간 숫자로 변환했다.

```javascript
Number(currentInput)
```

JavaScript의 명시적 형 변환과 암묵적 형 변환이 실제 코드에서 어떻게 작동하는지 확인했다.

---

### Refactoring

초기 구현에서는 하나의 Event Listener 안에 모든 로직이 존재했다.

이후 책임을 분리하여 다음 함수로 리팩토링했다.

* `calculate()`
* `clear()`
* `inputNumber()`
* `setOperator()`
* `updateDisplay()`

이를 통해 함수 하나가 하나의 역할을 담당하도록 개선했다.
